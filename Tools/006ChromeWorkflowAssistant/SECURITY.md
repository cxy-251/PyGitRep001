# Security Boundary

## 目标

扩展用于减少跨进程自动化和高频 AppleScript/CDP 调用，不用于规避网站安全机制。

## 权限

- `activeTab`：只访问用户点击扩展图标时的活动标签页；
- `scripting`：按用户动作注入本地内容脚本；
- `sidePanel`：显示持久侧边栏；
- `storage`：本地保存模板、表单和 X 提取结果。

不申请 Cookie、浏览历史、网络拦截、下载、调试器或全站访问权限。

## 写操作边界

- 快手：允许填字段，不允许点击最终发布；
- BOSS：允许填入消息，不允许点击发送；
- X：只读；
- 不自动滚动；
- 不后台循环；
- 不定时运行；
- 不重试不确定的写操作。

## 消息边界

Service Worker 只接受扩展自身侧边栏发出的消息，并校验动作白名单。内容脚本的返回值只作为页面数据处理，不能触发额外 Chrome 特权操作。

## 本地数据

以下内容保存在 `chrome.storage.local`：

- 快手表单草稿；
- BOSS 筛选词和消息模板；
- X 提取结果。

扩展不上传这些数据，不加载远程脚本，不调用第三方分析服务。

## 风控处理

内容脚本只检测页面上可见的验证码、安全验证和异常提示，并把信息显示到侧边栏。发现风险提示时不尝试关闭、隐藏、绕过或自动重试。
