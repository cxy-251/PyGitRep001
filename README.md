# PyGitRep001

这是一个个人历史代码归档仓库，保存过去完成的工具、一次性脚本、实验、学习笔记和程序生成数据。

仓库内项目已停止持续开发。代码按原路径保留，主要用途是：

- 根据功能快速找到旧实现；
- 回顾某个具体任务当时使用的代码；
- 为新项目复用思路，而不是直接继续维护旧项目。

## 功能索引

完整的“功能 → 代码”总表见：

- [ARCHIVE_INDEX.md](./ARCHIVE_INDEX.md)

索引会标明每项内容属于归档成品、一次性脚本、实验、学习记录、生成数据或高风险脚本，并直接链接到对应源码。

## 当前状态

- YouTube / yt-dlp 相关历史实现已被后续项目 `lyricMVPlayer` 取代。

部分脚本包含写死的 Windows 路径、Cookie 路径、盘符和旧依赖；部分 Notebook 会重命名、移动、覆盖或删除文件。运行前请先查看 [ARCHIVE_INDEX.md](./ARCHIVE_INDEX.md) 中的状态与风险说明，并使用测试数据。
